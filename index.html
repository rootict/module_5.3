5.3 THE CONCEPT

The Taxi Driver Analogy

Why vague instructions lead to bad destinations.

🚕
🚕
Weak Prompt
"Take me to the city."
Result: Driver chooses the longest route, drops you at a random spot, charges double.
VS
🚖
Strong Prompt
"Take me to IMA Campus in Malabe, use the highway, drop me at the main gate."
Result: Fast, accurate, exact destination reached perfectly.

The Tokyo Trip

Comparing outputs for a general planning task.

⚠️ The Lazy Ask
Plan a trip to Japan.
Japan Trip Plan:

Japan is a beautiful country. You can visit Tokyo, Kyoto, and Osaka. Make sure to eat sushi and ride the bullet train. The best time to go is Spring.

(Too generic, not actionable, no timeline.)
✅ The Master Prompt
Act as an expert travel agent. Plan a 5-day budget itinerary for 2 adults to Tokyo focusing on street food and anime culture. Limit travel time between spots to under 30 mins. Format as a daily Markdown table.

BATTLE 2: WORKPLACE COMMUNICATION

The Customer Complaint

Comparing outputs for a corporate writing task.

⚠️ The Lazy Ask
Write an email to complain about my broken laptop.
Hey,

My laptop is broken and it won't turn on. I am very angry because I need it for work. Please fix it or give me my money back immediately.

Thanks.

(Unprofessional, lacks details, aggressive tone.)
✅ The Master Prompt
Write a professional but firm email to Dell Support about a newly purchased XPS 15 with a defective screen. Request an immediate replacement under warranty. Keep it under 80 words. No angry language.
Subject: Warranty Replacement Request - Defective XPS 15 Screen

Dear Dell Support Team,

I am writing to report a hardware defect in my newly purchased Dell XPS 15 (Service Tag: [Insert Tag]). The screen displays severe flickering and dead pixels out of the box.

As this device is fully covered under the standard warranty, I kindly request an immediate unit replacement. Please advise on the return process.

Best regards,
[Your Name]

BATTLE 3: CODING & LOGIC

The Syntax Error

Comparing outputs for a technical debugging task.

⚠️ The Lazy Ask
Fix this HTML code:
<h1>Hello World</h2>
Here is the fixed code:

<h1>Hello World</h1>

(Provides the answer, but doesn't explain WHY it was wrong. Bad for learning.)
✅ The Master Prompt
Act as a Senior Web Developer mentoring a junior. Find the syntax error in the HTML code: <h1>Hello World</h2> Explain why it fails in 1 sentence. Provide the corrected code in a clean code block.
Explanation: The code fails because the opening tag (<h1>) does not match the closing tag (</h2>), which violates standard HTML tree structure rules.

Corrected Code:
<h1>Hello World</h1>

MODULE 5.3 SUMMARY

The Strong Prompt Checklist

Before hitting enter, check if you have these 4 pillars.

✅
🎯
1. Task
Did I use a strong action verb? (e.g., Write, Analyze, Code, Summarize)
📖
2. Context
Did I tell the AI who it is acting as, and why I need this information?
🚧
3. Constraints
Did I specify what the AI should NOT do? (Word limits, tone, jargon limits)
📋
4. Format
Did I request a specific output shape? (Markdown table, JSON, Bullet points)
