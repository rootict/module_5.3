# Module 05.3 - Comparing Weak vs. Strong Prompts

An interactive, web-based presentation designed for the **Foundation Diploma in Digital Technology, AI & Future Skills**. This module demonstrates why vague instructions lead to poor AI results through practical, real-world comparisons and the classic "Taxi Driver" analogy.

## 🎯 Learning Objectives
This presentation contrasts the effectiveness of poorly written prompts against master-level prompts:
* **The Taxi Driver Analogy:** Understanding why vague instructions result in wasted time and wrong destinations.
* **Battle 1 (Planning & Research):** Comparing a generic travel request against a structured, constraint-driven itinerary prompt.
* **Battle 2 (Workplace Communication):** Transforming an unprofessional, emotional complaint into a legally sound, polished corporate email.
* **Battle 3 (Coding & Logic):** Shifting from a simple syntax fix to an educational mentorship prompt that explains the root cause.
* **The Strong Prompt Checklist:** A 4-pillar recap (Task, Context, Constraints, Format) to review before hitting enter.

## ✨ Features
* **Interactive Side-by-Side Battles:** Click-through chat simulations comparing weak outputs against master-level outputs.
* **Practical Use Cases:** Real-world examples covering travel planning, customer service, and software debugging.
* **Zero Dependencies:** Built entirely with pure HTML, CSS, and vanilla JavaScript.
* **Fully Responsive:** Adapts smoothly across different screen sizes and classroom projectors.
